# OFFICE MBTI — 나의 회사생활 캐릭터는?

12문항으로 알아보는 16가지 회사생활 캐릭터 테스트와 동료 궁합 계산기입니다.
**재미로 즐기는 오락용 테스트이며, 검증된 심리검사가 아닙니다.**

- React 19 · TypeScript · Vite · Tailwind CSS v4
- 서버·회원가입 없음, 개인정보 수집 없음 (브라우저 localStorage만 사용)
- 모바일 우선 반응형, 키보드 조작 지원

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 채점·16유형·궁합·저장·공유 로직 테스트 (Vitest)
npm run build      # 타입 검사 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
```

`vite.config.ts`의 `base: './'` 덕분에 `dist/`를 GitHub Pages 등 어느 하위 경로에 올려도 동작합니다.

## 폴더 구조

```
src/
├─ data/
│  ├─ axes.ts          4개 성향 축 (E/I, P/F, L/H, D/S)
│  ├─ questions.ts     12문항 (축별 3문항, A/B 이지선다)
│  └─ types.ts         16개 캐릭터 데이터
├─ lib/
│  ├─ scoring.ts       축별 다수결 채점 → 유형 코드, 응답 선택 비율
│  ├─ compatibility.ts 궁합 점수(기본 50 + 축별 가산) · 협업 팁 · 궁합 좋은 유형
│  ├─ storage.ts       진행 상태/결과 localStorage 저장 (손상값 검증, 저장 불가 환경 대응)
│  ├─ router.ts        해시 라우팅, 공유 URL(유형 코드만 포함)
│  ├─ share.ts         공유 시트 → 클립보드 → 수동 복사 단계적 대체
│  ├─ image.ts         결과 카드 PNG 저장 (html-to-image, 폰트 실패 시 재시도)
│  └─ *.test.ts        자동 테스트
├─ components/         캐릭터 카드, 응답 비율 막대, 토스트, 공통 UI
├─ pages/              홈 / 테스트 / 결과 / 궁합
├─ hooks/useHashRoute.ts
├─ App.tsx  main.tsx  index.css
```

## 화면 주소

| 주소 | 화면 |
| --- | --- |
| `#/` | 홈 (이어서 하기, 내 결과 다시 보기) |
| `#/test` | 테스트 — 새로고침해도 진행 상태 유지 |
| `#/result/EPLD` | 결과 — 공유 링크는 유형 코드만 포함 |
| `#/match/EPLD/IFHS` | 동료 궁합 |

## 규칙

**채점**: 축마다 3문항 중 더 많이 고른 성향이 그 축의 글자가 됩니다. 모든 문항에 답해야 결과가 생성됩니다.
결과 화면의 막대는 "3문항 중 몇 번 골랐는지"를 그대로 보여 주는 응답 선택 비율이며, 측정 점수가 아닙니다.

**궁합** (오락용 임의 규칙): 기본 50점에서

| 축 | 같을 때 | 다를 때 |
| --- | --- | --- |
| 소통 방식 (E/I) | +15 | +5 |
| 업무 처리 (P/F) | +15 | +5 |
| 의사결정 (L/H) | +10 | +5 |
| 업무 태도 (D/S) | +5 | +10 |

모든 조합은 70~100점 사이이며, 결과 문구는 항상 긍정적으로 작성되어 있습니다.
